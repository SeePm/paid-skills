# X Ads: what to check per lens

Facts X documents publicly. Check the current X Business help when something looks off; X changes objectives and defaults often.

## X against Y
- The objective is set per campaign (reach, engagements, video views, website traffic, app installs, conversions, followers); the goal, bid, targeting and placements are set per ad group. Read each ad group.
- Website traffic ad groups can optimize for site visits or for link clicks. Link clicks buys clicks that may never load the page.
- Conversions campaigns need the X pixel or Conversion API sending the event the business values.

## Measurement
- Website conversion defaults are 30 days after an engagement and 1 day after a view. Engagement includes likes, reposts, follows and replies, not only clicks, so post-engagement conversions credit more than clicks.
- Changing the attribution window rewrites past conversion data. Note when it changed before comparing periods.
- Pixel and Conversion API together need the same conversion_id to deduplicate.
- App install and re-engagement campaigns bill on 30-day post-engagement and 1-day post-view regardless of the window chosen for reporting.

## Structure and spend
- Campaign budget optimization moves one campaign budget between ad groups; ad groups then cannot have their own budgets.
- Campaign, ad group and ad must all be on for anything to serve.

## Budget and pacing
- Standard delivery, the default, spreads spend through the day; accelerated delivery spends as fast as possible and can run out early.
